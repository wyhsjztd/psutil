# 系统监视器 用户手册

## 1. 安装与启动

### 1.0 直接运行 exe（推荐）

双击 `dist\SysMon.exe` 即可启动，不需要安装 Python，也不会弹出命令行窗口。

- 单文件约 60 MB，首次启动约 3 秒（需要先把运行库解压到临时目录）
- 程序图标已内置，关闭窗口后不会残留后台进程
- 若被杀毒软件拦截，请将 exe 加入信任列表（PyInstaller 打包的程序较常见）

### 1.1 从源码运行

双击 `run.bat`（使用 `pythonw` 启动，无控制台窗口），或在命令行执行 `python main.py`。

### 1.2 环境要求

- Windows 10 / 11
- Python 3.10 及以上
- 约 300 MB 磁盘空间（主要来自 PySide6）

### 1.3 安装步骤

```bash
# 克隆代码库
git clone <仓库地址>
cd psutil

# 创建虚拟环境（推荐）
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动
python main.py
```

若下载缓慢，可使用国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 2. 界面说明

程序启动后，窗口分为三个区域：

```
┌────────────────────────────────────────────────────────────┐
│ ● 系统监视器  DESKTOP-XXX   [采样间隔▾] [暂停] [导出 CSV]   │  ← 顶部工具栏
├──────────────┬─────────────────────────────────────────────┤
│  进程        │                                             │
│  CPU         │              当前页面                       │
│  内存        │         （大数字 + 实时曲线 + 统计）         │
│  磁盘        │                                             │
│  网络        │                                             │
│  磁盘 I/O    │                                             │
│  服务        │                                             │
│  用户        │                                             │
├──────────────┴─────────────────────────────────────────────┤
│ 最近采样 16:32:05 · 数据点 128 · ...                       │  ← 状态栏
└────────────────────────────────────────────────────────────┘
```

左侧导航卡片显示该指标的当前值与最近 60 秒的迷你曲线，点击切换到对应页面。

### 2.1 页面说明

| 页面 | 内容 |
|---|---|
| **进程** | 全部进程列表（名称 / PID / CPU / 内存）。可搜索进程名或 PID，点击表头排序，右键可结束任务 |
| **CPU** | 总利用率曲线（0–100%）、每个逻辑处理器的柱状图、当前频率、进程数、正常运行时间 |
| **内存** | 使用率曲线、已用/可用/总计、交换（分页）文件 |
| **磁盘** | 每个分区的使用率进度条、容量明细、当前读写速率 |
| **网络** | 接收/发送速率双曲线、累计流量、TCP 连接数 |
| **磁盘 I/O** | 读取/写入速率双曲线、累计读写量 |
| **服务** | Windows 服务列表，可按名称或显示名称搜索 |
| **用户** | 当前登录用户、主机、会话与登录时间 |

## 3. 常用操作

### 3.1 修改采样间隔

点击顶部「采样间隔」下拉框，可选 1 秒 / 2 秒 / 5 秒。

切换后程序会自动重建速率基线，因此不会出现"间隔变了、算出一个巨大尖峰"的问题；
曲线上新旧采样密度的点按各自的时间位置连续显示，不会中断。
历史数据仍保留在内存中，可完整导出。

### 3.2 暂停与继续

点击「暂停」停止采样，按钮变为「继续」。暂停期间界面保持最后一帧数据。

点击「继续」后，程序丢弃旧的速率基线并重新起算，第一帧速率显示 `--`，随后恢复正常。
暂停期间的曲线会显示为空白，而不是被一条直线连接。

### 3.3 导出数据

点击「导出 CSV」，选择保存位置即可。

- 导出范围为**本次运行期间的全部采样点**（最多 1 小时）；
- 文件编码为 UTF-8 with BOM，中文 Windows 上可直接用 Excel 双击打开；
- 表头包含单位，时间列为 ISO 8601 格式。

导出的列：时间、CPU(%)、内存(%)、磁盘最大使用率(%)、网络下行(B/s)、网络上行(B/s)、磁盘读(B/s)、磁盘写(B/s)、进程数。

### 3.4 结束进程

在「进程」页右键单击任意进程，选择「结束任务：进程名 (PID)」，确认后即可结束。

> 结束系统关键进程可能导致系统不稳定，请谨慎操作。
> 若提示"权限不足"，请以管理员身份重新启动程序。

### 3.5 搜索与排序

- **搜索**：在进程页或服务页顶部输入框输入关键字，列表实时过滤；
- **排序**：单击表头可在升序/降序之间切换，数值列按数值大小排序而非按字符串。

## 4. 状态栏提示

| 提示 | 含义 |
|---|---|
| 正在建立采样基线 | 刚启动、暂停恢复或切换间隔，速率尚未就绪 |
| ⚠ CPU 占用率过高 | CPU 连续超过 80%，解除阈值 75%，两次提示间隔至少 5 分钟 |
| 采集异常：磁盘 / 网络 | 该指标本次读取失败，其余指标不受影响 |

## 5. 常见问题

**Q：网络速率显示 `--`？**

A：程序刚启动、暂停恢复后、或系统卡顿导致采样间隔异常时，速率需要重新建立基线，约 1 秒后自动恢复。

**Q：数值与任务管理器不一致？**

A：
- 网络：任务管理器可能以 Mbps 显示，本程序以 MB/s（字节）显示，需乘以 8 换算；
- 磁盘：注意三者的区别 —— 左侧「磁盘」卡片与磁盘页的**活动时间**对应任务管理器的磁盘百分比；
  磁盘页分区列表里的百分比是**容量使用率**（磁盘装得多满），与系统忙闲无关；
  磁盘 I/O 页则是**吞吐量（B/s）**；
- CPU：本程序与任务管理器都按「频率加权」口径统计，可放心对比；
  但 perfmon 等工具默认显示的是「时间占比」，睿频时会低很多，这是正常的；
- 进程 CPU：本程序为 3 秒区间均值，任务管理器为瞬时值，允许存在小幅差异。

**Q：磁盘页缺少某个分区？**

A：光驱、已拔出的移动硬盘、网络映射盘会被自动过滤，避免访问无效设备导致界面卡死。

**Q：服务页一直显示"正在读取…"？**

A：服务枚举通过 WMI 完成，首次加载可能需要数秒，之后每 30 秒刷新一次。若长时间无数据，可能是不支持该 API 的平台。

**Q：关闭窗口后进程没有退出？**

A：正常情况下关闭窗口即退出。若出现异常，可在任务管理器中结束 `python.exe` 进程。程序的采样线程使用可中断等待，正常退出不会残留。
